# 港口镇连续杀人事件 · 简体中文汉化补丁

当前版本：**v1.1.0**（2026-10-20）

## 日文原版 ROM

本补丁不包含原版 ROM，请自行准备未经修改、保留 16 字节文件头的日版 ROM，完整文件大小 40,976 字节。
支持两种文件头；CRC32 与 SHA-256 均按完整文件计算，不能只核对去头数据。
请按校验值选择源文件，不要按文件名或压缩包名称猜测。

|日文原版|文件头|CRC32|SHA-256|
|---|---|---|---|
|NES 2.0 版本|NES 2.0|`0633BA05`|`4e711f78d0f7f31a3fa395159d51556370d8a361d26e2b2910c43efc2fe1ea53`|
|No-Intro 版本|iNES 1|`9B2B749B`|`fbb85d0baf543e4d492ed74a95b28c3d7f51849d09a053ce6dcfe9a9ef07ec16`|

两种源仅文件头第 7、15 字节不同，去头数据相同。

|NES 2.0|`portopia_cn_v1.1.0.bps`|`60759aeed1eb92a00a5af30c2cf93f913bbce1f3377c6079957cb119b379173e`|
|iNES 1（No-Intro）|`portopia_cn_v1.1.0_ines1.bps`|`66d9d52d64bc820039a2fd38448f8683d6d942f32622ad350c7e7304d4c71ada`|

两份补丁应用后生成同一个中文 ROM；不能把源文件与补丁混用。
文件名中的 `_ines1` 表示源文件格式，不是另一个版本。

## 应用补丁

1. 备份原版 ROM，核对完整文件大小、CRC32 与 SHA-256。
2. 使用支持 **BPS** 格式的补丁工具，如[Floating IPS](https://www.romhacking.net/utilities/1040/)，选择与源文件对应的补丁。
3. 将匹配的日文原版 ROM 选为源文件，输出保存为新文件，保留原版 ROM。
4. 检查生成的 ROM：大小应为 **524,304 字节**，SHA-256 应与下文一致。
5. 用支持 **Mapper 192** 的模拟器打开新 ROM，从新游戏冷启动；只支持原日版所用 Mapper 的模拟器未必能运行汉化版。

旧版即时存档可能包含旧渲染代码及图集状态。升级后请先从新游戏启动，不要直接加载旧版即时存档；跨版本即时存档兼容性未作保证。
