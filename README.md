# 港口镇连续杀人事件 · 简体中文汉化补丁

## 日文原版 ROM 相关信息

本补丁仅适用于以下**未经修改、带 16 字节 iNES 文件头的日文原版 ROM**：

| 项目 | 要求 |
| --- | --- |
| 游戏 | ポートピア連続殺人事件（Portopia Renzoku Satsujin Jiken） |
| 平台／地区 | FC／NES，日本版 |
| 文件格式 | `.nes`，保留 16 字节 iNES 头 |
| 完整文件大小 | **40,976 字节** |
| SHA-256 计算范围 | 整个 `.nes` 文件，包含文件头 |

**原版 ROM 的 SHA-256：**

```text
4e711f78d0f7f31a3fa395159d51556370d8a361d26e2b2910c43efc2fe1ea53
```

## 应用补丁

1. 备份原版 ROM，并按上文检查文件大小和 SHA-256。
2. 使用支持 **BPS** 格式的补丁工具，如[Floating IPS](https://www.romhacking.net/utilities/1040/)，选择 `portopia_cn_v1.1.0.bps`。
3. 将符合校验要求的日文原版 ROM 选为源文件。
4. 将输出保存为新文件，例如 `portopia_cn_v1.1.0.nes`，保留原版 ROM。
5. 检查生成的 ROM：大小应为 **524,304 字节**，SHA-256 应与下文一致。
6. 用支持 **Mapper 192** 的模拟器打开新 ROM，从新游戏冷启动。

旧版即时存档可能包含旧版渲染代码及图集状态。升级后请先从新游戏启动，不要直接加载旧版即时存档；跨版本即时存档兼容性未作保证。

## 运行与验证范围

需要模拟器支持 Mapper 192；仅支持原日版所用 Mapper 的模拟器未必能运行汉化版。项目既有自动验证使用 Mesen2 2.2.1，未完成实机及其他模拟器认证。

遇到问题时，请记录补丁版本、生成 ROM 的 SHA-256、模拟器名称和版本、复现步骤，并说明是否加载过旧版即时存档。截图或录像有助于定位。
